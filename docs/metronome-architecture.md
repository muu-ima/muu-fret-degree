# メトロノームの設計

[アーキテクチャ全体へ戻る](architecture.md)

この文書は `app/hooks/audio/useMetronome.ts` と関連する予約再生・ノートミキシングの設計をまとめる。

## 再生の責務とライフサイクル

メトロノームの開始・停止、表示状態、音声予約のライフサイクルを担当する。

- ユーザー操作で共有AudioContextの再開を要求し、再開完了後に音声時計で再生を始める。再開待ちの間に停止・再開始・画面移動した場合は、古い処理を開始しない。
- `app/lib/metronome-playback.ts` は1拍12分割の発音時刻を計算し、25msごとの呼び出しで100ms先まで予約する。タイマーの呼び出し時刻を発音時刻には使わない。
- `app/lib/metronome-audio-session.ts` は共有出力へ接続するメトロノーム専用GainNodeを作る。停止時はこの出力を消音・切断し、予約済みクリックも聞こえなくする。他の楽器の出力や共有AudioContextは停止しない。
- BPM・ミックス音量・音色の変更は未予約のステップから反映し、再生位置は戻さない。拍子・カウントイン設定の変更は従来どおり先頭から再開始する。
- 拍表示とCount-in完了通知は音声時計が対象時刻に達してから更新する。完了通知は1回だけ発火し、停止後には発火しない。
- 長いメインスレッド停止で予約が間に合わない場合、期限切れの音は飛ばし、まとめて鳴らさない。長い停止中やバックグラウンドでも無音区間が生じないことを保証する方式ではない。
- クリック用OscillatorNodeとGainNodeは発音終了後に接続を解放する。

コード進行の開始は従来のReact側コールバック経由のままなので、カウントイン後のクリックと伴奏の厳密な音声時刻同期は別の課題とする。画面表示と完了通知はポーリングや描画処理の遅延を受けるが、予約済みクリックの発音間隔には影響しない。

## 予約再生への変更と確認状況（2026-11-22）

従来のタイマーが呼ばれた時点でクリックを鳴らす方式では、メインスレッドの処理遅延が発音間隔に影響していた。現在はTrainingと同様にAudioContextの時刻を基準に先読み予約し、タイマーは予約を補充する役割に限定する。今後の変更でも、発音時刻の決定と画面表示の更新を分離する方針を維持する。

予約再生への変更後、ユーザーから「パルスが安定している」と聴感での改善報告があった。これは利用環境での確認結果であり、全デバイスでの保証や発音間隔の実測結果ではない。今後はこの状態を基準に、再生中のテンポ変更とTrainingとの切り替えを順に確認する。

## ノートミキシング（第1段階）

BOSS DB-90の[公式仕様](https://www.boss.info/jp/products/db-90/)にある4種類のリズムとアクセントの独立音量を参考に、メトロノームをノートミキサー方式に統一する。再生モード切り替えと旧Pulse・Swing・アクセントチェックボックスは廃止した。今回はノートミキシングのみを対象とし、メモリー、コーチ、ドラムパターン、外部入力、実機風の外装は今後の別段階とする。

- `app/lib/metronome-mixer.ts`: 1拍12分割の共通グリッドで発音と音量を決める純粋関数。4分はstep 0、8分の裏はstep 6、16分の裏はstep 3・9、三連はstep 0・4・8で鳴らす。4分と裏拍のチャンネルは拍頭を重複させず、三連など重なった通常音は合算して1に制限する。小節頭のアクセントは別イベントとして加える。
- `app/components/practice/MetronomeMixer.tsx`: 各チャンネルの音量スライダーを表示し、変更をcallbackで通知する。縦スライダーのスタイルは専用CSSに閉じる。
- `PracticeWorkspace`: チャンネル音量を所有する。ミキサーは常時表示する。
- `useMetronome`: 12分割のStraightグリッドを使う。BPM・音量・音色はrefから読み、変更で予約スケジューラーを再起動しない。カウントインではミックス音量によらず四分音符を鳴らし、終了callbackを従来どおり1回呼ぶ。

Trainingの順次切り替え再生は変更しない。メトロノームは既存の共有音声出力を使い、音声時計で先読み予約する。

## アクセントと均一なクリック

メトロノームでは通常音を `subdivision` で統一し、小節頭のアクセント音量を独立スライダーで調整する。アクセント0%、4分と8分の裏を同じ音量にすると均一な八分音符になる。

Trainingは従来のアクセントチェックボックスを維持し、`app/lib/metronome-click.ts` の `getMetronomeClickKind` を使う。オフでは全音を `subdivision`、オンでは小節頭を `accent`、他の拍頭を `beat`、細分音を `subdivision` とする。

両者とも音量・アクセント変更で再生位置をリセットしない。両者ともAudioContext時刻を使った予約再生だが、それぞれの再生セッションは別々に管理する。
